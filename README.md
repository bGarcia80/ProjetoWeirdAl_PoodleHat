## **🎩 Projeto Weird Al — Poodle Hat**
### Um projeto dedicado ao álbum *Poodle Hat*, de "Weird Al" Yankovic.

-------------------------------------------------------------------------------------------------------------------------

Este projeto consiste em uma página dedicada ao álbum *Poodle Hat*, reunindo informações, curiosidades, tracklist e diferentes materiais relacionados ao décimo primeiro álbum de estúdio de "Weird Al" Yankovic, lançado originalmente em 20 de maio de 2003.

A página foi finalizada, contando com uma estrutura organizada para apresentar informações sobre o álbum e seus conteúdos relacionados.

--------------------------------------------------------------------------------------------------------------------------

🌐 **Acesse o projeto**

Você pode acessar a página finalizada através do link:

https://bgarcia80.github.io/ProjetoWeirdAl_PoodleHat/

---------------------------------------------------------------------------------------------------------------------------

📀 **Sobre o projeto**

A proposta foi desenvolver uma página especial sobre *Poodle Hat*, explorando diferentes aspectos do álbum, incluindo:

- Informações sobre o álbum;
- História e curiosidades;
- Tracklist completa;
- Informações sobre as músicas;
- Capas e artworks;
- Outros conteúdos relacionados ao álbum.

O projeto foi desenvolvido com o objetivo de reunir essas informações em um único lugar, utilizando uma estrutura simples e organizada para facilitar a navegação e a consulta dos conteúdos.

--------------------------------------------------------------------------------------------------------------

✅ **Projeto finalizado**

O desenvolvimento da página foi concluído, e o projeto está disponível para acesso através do GitHub Pages.
